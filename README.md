# TelegramBot

Минимальный Telegram-бот: отвечает символом `.` на команду `/start`.

## Запуск

Требуется Python 3.10 или новее.

1. Установите зависимости: `pip install -r requirements.txt`
2. Установите переменную окружения `BOT_TOKEN` со свежим токеном от BotFather.
3. Запустите: `python main.py`

Добавьте секрет с именем `BOT_TOKEN` в настройках хостинга. Не вставляйте токен в исходный код и не публикуйте его в GitHub.
